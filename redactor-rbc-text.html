    Redacted text is replaced with a numbered marker. Pending suggestions remain visible until you decide.

    Find uses literal text, including matches inside longer words. Inspect every occurrence. A larger marked passage replaces decisions fully inside it and needs a fresh review. Partial overlaps are skipped. Removing a decision restores automatic suggestions; use Keep with a reason to retain an identifier.

    A group decision applies only to pending items on the current page, with the same reason. Reasons record your judgement; they do not establish a legal exemption. Do not include withheld text in reasons.

    Internal working files contain decisions, reasons and reviewer details, not the source text. Keep them with the unchanged original. Restoring checks the source fingerprints and resets release declarations. They are not disclosure copies or authenticated approvals.

    03 Check & export

    Review required

    Names are self-declared. This tool does not authenticate reviewers or provide a tamper-proof audit trail.

    Load a source to start the review.

    The decision record includes reasons, reviewer names, source ranges and SHA-256 fingerprints, but no source excerpts. It may still be sensitive: store it separately from the disclosure copy. Source or review changes cancel prepared exports and require review again.

    Pasted-text exports use a new simple document layout. Word-source exports are blocked because this engine cannot preserve the original layout, numbering and pagination.

    What this pilot does and does not cover

    This is a single-document evaluation tool. It supports text exports and review of supported DOCX files. Word-source exports are blocked pending a layout-preserving engine. Text exports create a new document containing only the release text. It does not copy original metadata, attachments, comments, relationship targets or revision history.

    It does not support PDF, OCR, scanned pages, images, tracked changes, Word fields, equations or content controls. Names and contextual identification require manual review. It does not decide privilege, exemptions or disclosure obligations. A clean scan is never a finding that a document is anonymous or safe to disclose.

    It does not preserve document layout, provide secure case storage or implement authenticated approval. Browser memory is cleared by abandoning the session; this is not a secure-erasure guarantee. Use an approved device and retain the original separately.
