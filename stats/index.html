Before interpreting these figures

    Logged requests

    —

    Parsed requests in the main export. Includes automated traffic and asset requests.

    Daily visitor identities

    —

    IP + browser + day. A returning person can count again each day.

    Listed page requests

    —

    GET requests for page-like URLs in the exported rows. Not unique readers.

    Data transferred

    —

    MiB served in the main export. A MiB is 1,048,576 bytes.

    Requests over time

    Daily totals from the main report. The last day may be incomplete. Missing dates are not filled with zeroes.

    Pages requested

    Page-like GET URLs only, excluding assets, feeds and event endpoints. Requests can include bots, reloads and unsuccessful responses depending on the export filters. Visitor identities are per URL and must not be added together.

    PDF activity

    Loading…

    The PDF export may cover selected files only. Its generator includes HTTP 200 and 304 responses. A request is not proof of a completed download or a read.

    Referring sites

    External referring hosts in the main export. Internal eMote referrals are excluded here. Missing referrers cannot be reliably calculated from this list.

    Recorded interactions

    These are event counts, not unique people or verified reading time. The current summary format has no reporting dates, so these events are not compared with the main period.

    Article events

    “Engaged” is the tracker’s event label. The threshold is not supplied in this export. The ratio is engaged events ÷ open events, not a percentage of unique readers.

    Game events

    Starts and completions are counted independently. They are not matched sessions, so a completion rate cannot be established.

    Data sources, checks and definitions

    Report health

    Each export is checked independently. Matching date ranges alone do not establish matching filters or populations. “Unavailable” means the file could not be loaded or has an unsupported format.

    Why some old metrics have gone

    Request counts cannot establish engagement. Counts of visitors to different pages overlap. Subtracting the debug report from the main report does not measure HTTP errors. Data-centre networks and missing referrers do not reliably identify bots.

    The separately filtered humans.json report is not treated as a verified human audience. The games.json report contains requests beyond game pages and is not used as a game engagement total.

    Definitions

    GoAccess “valid requests” means parsed log entries, not successful visits. Daily visitor identities use IP address, date and user agent. These can merge different people or count one person more than once. See the GoAccess manual.

    PDF paths are read from both regular and static request panels. Query-string variants are kept separate to avoid adding visitor identities across overlapping rows. No visitor totals are built by adding page rows.

    Server-log and event summaries. No new visitor tracking is added by this dashboard.
